# FileSender

**FileSender** - это C++17 приложение для обмена текстовыми сообщениями и файлами по сети с поддержкой расширяемого протокола, потоковой передачи и шифрования.

Проект спроектирован с упором на:
- чистую архитектуру
- расширяемость (handlers / transport / security)

---

## Возможности

- Передача текстовых сообщений
- Передача файлов (metadata + chunks + end)
- Поддержка шифрования (через отдельный класс, унаследованный от `ISecurity`)
- Клиент и сервер в одном приложении
- Packet Dispatcher с обработчиками

---

## Архитектура

```text
+------------+
| Transport  |  (TCP, позже UDP)
+------------+
      |
      V
+------------+
|   Packet   |  (сериализация и десериализация)
+------------+
      |
      V
+------------+
|   Security |  (шифрование и дешифрование)
+------------+
      |
      V
+------------+
| Dispatcher |  (маршрутизация пакетов)
+------------+
      |
      V
+------------+
|  Handlers  |  (FileHandlers, TextHandler)
+------------+
```

## Протокол передачи

Каждый пакет имеет следующую структуру:

+------------+-------------------+------------------+---------+
|  Type (1B) |  Encryption (4B)  |     Size (4B)    |   Data  |
+------------+-------------------+------------------+---------+

Типы пакетов:

- TextMessage
- FileMeta
- FileChunk
- FileEnd

## Сборка

```
mkdir build
cd build
cmake .. && make
```

## Запуск

### Сервер
```
./app <name_server_log_file> server <port>
```

### Клиент
```
./app <name_client_log_file> client <host> <port>
```
